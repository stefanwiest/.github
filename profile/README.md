## 🔬 Research Focus

We research how AI agents coordinate at scale using musical ontology and biological feedback loops.

> **"Orchestration is explicit. Coordination is emergent."**

### Core Projects

| Project | Description | Role |
| :--- | :--- | :--- |
| **[hct-core](https://github.com/stefanwiest/hct-core)** | **Harmonic Coordination Theory**. A musical ontology for multi-agent coordination (Cues, Fermatas, Tempo). | *The Protocol* |
| **[genesis](https://github.com/stefanwiest/genesis)** | **Evolutionary Agent Operating System**. Implements SVRL (Socratic Verification) and Glass Box optimization. | *The Platform* |
| **[hct-benchmarks](https://github.com/stefanwiest/hct-benchmarks)** | Validation suite for measuring coordination quality and dissonance in agent systems. | *The Metric* |
